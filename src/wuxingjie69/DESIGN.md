# 吴兴街69号 · 状态栏

只展示当前消息楼层的16个MVU字段，不写回、不补默认值，不自动推进关系或相认。

视觉：旧日历的日期栏、门牌印记、记账簿的存款、横线便笺里的近期事务。纸色承载信息，砖红用于关系，灰绿用于信任与街坊认可。系统宋体标题与清晰黑体正文，无额外字体网络请求、无图片、无emoji、无发光效果。

结构：日期/场景 → 心蕾近况与秦朗生计双栏 → 阿嬷/街坊/秦海 → 近期事务。小屏下认可区变两栏，极窄屏日常区变单栏；正文自然撑高，不设固定高度、vh或内部滚动。

数据：遵循mvu-variables.md写法B。先显示全部“—”，等待MVU初始化和本楼层stat_data落表，再每2秒与变量更新事件只读刷新。各字段独立验证；字符串不回译、不繁简转换，Vue文本插值转义。空事务数组显示“暂无近期事务”，缺失/null/错误类型显示“—”。好感阈值60/75/88仅派生显示；不写入关系阶段。

项目事实来自卡片state及其引用文件。卡片原design-spec、schema、世界书和开场白不改。schema.ts是原文件只读副本，不用于默认值填充。预览数据来自state所引用的initvar；仅测试页面加载，生产构建不引用。
